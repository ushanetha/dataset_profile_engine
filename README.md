# Dataset Profiling Engine

## Overview

Dataset Profiling Engine is a reusable Python application designed to analyze datasets and generate detailed profiling information.

The application supports CSV, Excel, and JSON datasets.

## Features

- Dataset schema detection
- Data type identification
- Missing value analysis
- Duplicate row detection
- Unique value analysis
- Numeric statistical analysis
- Categorical data summary
- Distribution visualization
- JSON profiling report generation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Supported File Formats

- CSV
- Excel (.xlsx, .xls)
- JSON

## Installation

Install required libraries:

pip install -r requirements.txt

## Running the Project

Run:

python main.py

Enter the dataset file path when prompted.

Example:

data/sample_data.csv

## Output

The application generates:

- Console profiling report
- JSON profiling report
- Distribution graphs for numeric columns

All generated reports are stored inside the reports folder.
